## D. 実装時に自分で決めた（合意を取っていない）こと

| # | 決めたこと | 理由 |
|---|---|---|
| D-1 | アクセントカラーを参考デザインより濃い `#4a7268` にした | 参考デザインの明るいセージ（概ね `#7ba296`）では白文字とのコントラストが 2.8:1 で、本文が読みにくかった。濃度を上げて 5.3:1（WCAG AA）を確保している。**色味を参考デザインに戻す場合は、帯の文字色を黒にする必要がある** |
| D-2 | ヒーローに抽象グラフのSVGを置いた | 写真を使わない方針のため。参考デザインの構図を踏襲 |

| D-4 | 事例をCMS化せず固定掲載にした | 要件定義書 §3 の合意事項どおり |
| D-5 | 添付ファイルの上限を10MBにした | 決算書PDFなら十分。Lark のアップロードAPIの制約ではない |
