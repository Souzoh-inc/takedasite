## 3. 作らないもの（意図的な非実装）

**実装時に「気を利かせて」追加しないこと。** すべて武田様との合意事項。

| 機能 | 理由 |
|---|---|
| 料金表の掲載 | 会社ごとに適用金額が変わるため。無料相談へ誘導する導線とする。ある程度の規模の事務所は非掲載が主流 |
| コラム・ブログ | 作成しない（合意事項） |
| ロゴ | 作成しない。事業形態確定後に再検討 |
| 採用ページ | 作成しない |
| 事例紹介 | **2026-10-03 の修正事項で掲載自体を削除。**当初は固定掲載の予定だった。税理士の業務はイメージしやすく、事例を期待して訪問する人はほとんどいない（コンサル会社なら必要だが税理士法人では不要、武田様談） |
| 顔写真 | 顔出しなし（ヒーローの都市の写真は 11/6 の修正事項でB案のものを使用） |
| SEO / MEO施策 | 検索経由の集客を狙わないため初回スコープ外 |
