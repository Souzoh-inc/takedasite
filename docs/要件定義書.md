## 3. 作らないもの（意図的な非実装）

**実装時に「気を利かせて」追加しないこと。** すべて武田様との合意事項。

| 機能 | 理由 |
|---|---|
| 料金表の掲載 | 会社ごとに適用金額が変わるため。無料相談へ誘導する導線とする。ある程度の規模の事務所は非掲載が主流 |
| コラム・ブログ | 作成しない（合意事項） |
| ロゴ | 作成しない。事業形態確定後に再検討 |
| 採用ページ | 作成しない |
| 事例紹介のCMS化 | 固定掲載とする。税理士の業務はイメージしやすく、事例を期待して訪問する人はほとんどいない（コンサル会社なら必要だが税理士法人では不要、武田様談） |
| 写真の使用 | 顔出しなし。余白・文字組み・図解・数字で構成する |
| SEO / MEO施策 | 検索経由の集客を狙わないため初回スコープ外 |

## 5. お問い合わせまわり

| 項目 | 決定内容 |

| フォーム構成 | 「決算書の無料診断」と「お問い合わせ」を**1ページに統合し、選択方式**とする（別ページ案から変更。理由: どちらを開いても入力内容がほぼ変わらないため。ただし「決算書の無料診断」という表記自体にインパクトがあるので残す） |

## 10. 武田様からの回収待ち事項

### 第2回MTG（2026-09-07）で完了したもの

武田様が画面共有しながらその場で実施し、いずれも菊池が承諾済み。

- Cloudflare アカウント作成 → 菊池を管理者権限で招待
- microCMS サービス作成 → 菊池を管理者で招待
- Lark Base 新規作成 → 開発者コンソールで「問い合わせ管理」カスタムアプリを作成し、
  bitable 系スコープ2つを付与のうえバージョン作成・リリース申請。Base にアプリを
  編集権限で追加し、菊池を「管理可能」で共同編集者に招待
- **App ID / App Secret を Lark グループに送付済み**
