## 3. 作らないもの（意図的な非実装）

**実装時に「気を利かせて」追加しないこと。** すべて武田様との合意事項。

| 機能 | 理由 |
|---|---|
| 料金表の掲載 | 会社ごとに適用金額が変わるため。無料相談へ誘導する導線とする。ある程度の規模の事務所は非掲載が主流 |
| コラム・ブログ | 作成しない（合意事項） |
| ロゴ | 作成しない。事業形態確定後に再検討 |
| 採用ページ | 作成しない |
| 事例紹介のCMS化 | 固定掲載とする。税理士の業務はイメージしやすく、事例を期待して訪問する人はほとんどいない（コンサル会社なら必要だが税理士法人では不要、武田様談） |
| 写真の使用 | 顔出しなし。余白・文字組み・図解・数字で構成する |
| SEO / MEO施策 | 検索経由の集客を狙わないため初回スコープ外 |

## 5. お問い合わせまわり

| 項目 | 決定内容 |
|---|---|
| フォーム構成 | 「決算書の無料診断」と「お問い合わせ」を**1ページに統合し、選択方式**とする（別ページ案から変更。理由: どちらを開いても入力内容がほぼ変わらないため。ただし「決算書の無料診断」という表記自体にインパクトがあるので残す） |
| 入力項目 | 会社名／お名前／メールアドレス／ご相談内容　＋　ご希望の種別 |
| 決算書の添付 | アップロード機能を任意で設置。**添付なしでも送信可能** |
| 問い合わせ管理 | 現状のExcel管理からLark Baseに集約。対応ステータス管理、対応期日の自動通知 |
| プライバシーポリシー | ソウゾウで叩き台作成 → 武田様がリーガルチェック |

- 参考値: 現在の無料診断の問い合わせ件数は月6〜7件
- 一般公開しない運用でも、フォーム送信内容はLark Baseに蓄積される

## 9. 未確定・要確認事項（推測で実装しないこと）

| 論点 | 内容 | 影響範囲 |
|---|---|---|
| **社名・ドメイン名** | 9月から個人事業主になる可能性があり、その場合「UNITE税理士法人」→「武田税理士事務所」に改称の可能性。さらに1年後に再法人化の可能性もある | 社名表記・ドメイン名・ロゴ・会社概要すべてに影響 |
| ドメイン名の方針 | 推奨案（A）は屋号に左右されないドメイン名（スケジュール影響なし、改称・法人化どちらでも使い続けられる）。ただし最終決定は武田様次第 | ドメイン取得作業の起点 |
| デザイン最終確定 | 3案提示済み。武田様は「どれも良い」「シンプル・白基調が良い」との評価で、C案にも好意的な言及あり。**正式な選定回答が来ているか要確認**（本書ではC案前提で進める） | デザイン実装の起点 |
| 初稿（HTMLたたき）の現状 | 本書作成時点での進捗状況は別途確認が必要 | 実装着手のスコープ |
